# Red Bull Energy Showcase

An interactive single-page product showcase inspired by Red Bull’s energy drink landing experience. The page focuses on premium motion, full-width hero transitions, responsive product storytelling, and polished brand-forward sections.

## Highlights

- Scroll-driven hero card transitions
- Responsive product and edition layouts
- Animated company and sustainability sections
- Production security headers at the edge
- Optimized static assets and deployable Cloudflare Worker output

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```
